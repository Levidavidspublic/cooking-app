# Cooking App

Cooking App helps a cook adapt a recipe to the people and equipment available, understand the ingredient tradeoffs, and improve a saved version after cooking it. Recipe Alchemist remains a working name.

The verified repository is still an inherited scaffold. The proposed product is documented here; no complete Cooking engine, accepted kitchen preview, expert validation or launch has been proved.
