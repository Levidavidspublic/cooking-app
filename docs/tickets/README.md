# docs/tickets — factory tickets

One folder per batch: `docs/tickets/<batch>/`, one file per ticket. Written by the ticket writer as ONE `config` PR "Tickets <batch>"; Amit merges it; then the promoter creates one issue per file. Templates arrive with Phase 08 (tempo-rhythm has them in docs/tickets/_templates/). Changes here go only through `config` PRs that change nothing outside docs/tickets/ and docs/contracts/.
